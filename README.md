# 均衡命途 · 站桩推演

一个为零依赖单文件网页做的战斗节奏模拟器：给定行动值预算与怪物数量，推演队伍中每个角色的**行动次数、终结技次数、能量与专属资源的循环**，并给出自动诊断。

单文件、无外部依赖、无网络请求，双击 `index.html` 即可在浏览器中运行。

## 它解决什么问题

回合制战斗里，"这条循环能不能在战斗时长内闭合"是所有配装与配速决策的前置问题。凭感觉算容易漏掉三件事：行动值溢出、资源上限导致的浪费、以及审判/终结技之间的先后依赖。这个页面把这些量显示化：

- **时间轴**：以行动值（AV）为横轴，逐单位、逐回合标出普攻 / 战技 / 终结技 / 审判技，结界覆盖区间以带状标出
- **资源曲线**：恶值、公平值、纸片鳞、双份能量各一张，带门槛线与上限线，能直接看出"差几点"和"溢出在哪一段"
- **循环明细**：每个角色的行动数、技能构成、大招时点与平均间隔、状态判定
- **策略对比**：同一次战斗的两种打法并排量化（如"门槛即审判" vs "蓄满再审判"）
- **自动诊断**：把规则层面的矛盾写成可读结论，而不是只丢一堆数字

## 建模对象

页面按一份《均衡》命途的角色设计文档建模，四个单位各有不同的资源口径：

| 单位 | 资源口径 | 说明 |
|---|---|---|
| 弥诺娅 | 公平值 ≤170 | 恶值经审判技回收后按系数转化，满 130 开大 |
| 霍霍·冥焰 | 能量 170 | 常规能量口径 |
| 欧比利斯 | 纸片鳞 ≤10 | 攒满即开，无溢出浪费 |
| 月青 | 能量 190 | 常规能量口径 |

另含一支**参照队**（银狼 LV.999 欢愉队：银狼 + 阿哈 + 爻光 + 真珠），用于同场景下的双队对照，面板会分别列出两队的结构性优势与短板。

## 可调参数

左侧栏可实时调整，改动即刻重算：

- 战斗时长（AV 预算）、敌方数量（1–5 个站桩目标）
- 四人速度与行动模式（普攻 / 战技的序列，如 `AAS`、`AS`）
- **进战初始资源**：四人各自的起手能量 / 公平值 / 纸片鳞，够门槛会在 0 AV 当场开大
- 公平值系数、审判技策略、结界追攻、战技点限制、秘技等开关

## 模型口径（重要）

页面里的数值分两类，必须分开看：

1. **设计文档中明确写出的**：资源上限、门槛、每段行为的资源增减、角色速度与行动模式。这部分按文档逐条对齐。
2. **文档未写明、为跑通模型而设的**：公平值的转化系数、欢愉队侧的笑点产出与隐藏分换算、部分行动模式。这些做成侧栏可调参数，并在页面底部"模型口径"区逐条标注了取值与理由。

换句话说，**结论的方向性比绝对值可靠**：比如"门槛审判的单次转化低于蓄满审判"是由公式的线性结构决定的，不随系数取值改变；而"某角色在某时长内能开 2 次还是 3 次大"则依赖具体参数，需要按你的实际配置校准后再读。

## 已知的设计层问题

写这个模拟器时发现的几处规则冲突（页面"自动诊断"里也会提示）：

- `公平值 =(恶−善)×系数` 对恶值线性，而恶值可用区间只有 5 个刻度，导致"解锁即审判"在数学上劣于"蓄满审判"，那个额外回合的正反馈被自己的公式抵消
- 结界追攻的"我方攻击后回 1 战技点"若按字面实现，会让战技点长期溢出，从资源管理退化为恒满状态
- 纸片鳞的"折学家每回合 +1"不在"各触发一次"的限制内，实际承担了主供水，与文档把它写成战技附带效果的表述不一致

## 使用

```bash
# 直接打开
open index.html        # macOS
start index.html       # Windows

# 或起个本地服务
python -m http.server 8000
```
